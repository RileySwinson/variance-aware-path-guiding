# Binary Tile Coding - Standalone Ver.

To facilitate the usage of the *Binary Tile Coding* data structure outside the confinements of this framework (or Mitsuba) for testing / referencing purposes, a standalone drag n' drop source + header file version have been provided below. As of August 2025, I unfortunately have not yet had the possibility to test this thoroughly, so I cannot guarantee that it will work without any issues. You may need to adjust parameters, visibility macros (e.g., Mitsuba often requires MTS_EXPORT_CORE) and change the implementation here and there.

The code assumes you are running C++14.
